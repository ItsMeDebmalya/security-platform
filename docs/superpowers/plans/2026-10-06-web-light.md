# Web Light (Tool 4a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `scanners/web/` — the Website Scanner's Light mode (Tool 4a): bounded, passive, evidence-paired header/transport/disclosure/listing/fingerprint/EOL checks, gated on a frozen lab corpus, live-verified and benchmarked.

**Architecture:** Gather first, then judge. `fetch.py` makes at most 12 ordinary GETs through `ctx.http` and returns one frozen `Observations`; pure analyzer modules (`html`, `headers`, `csp`, `disclosure`, `listing`, `challenge`, `fingerprint`, `eol`) judge it; `scanner.py` emits findings via `Finding.create` with state always derived. Header claims are validated by re-reading the policy on the 404 control.

**Tech Stack:** Python 3.13, stdlib `html.parser`, PyYAML (already a dependency), `core/` import-only, pytest, a docker-compose lab (nginx + two python:3.13-slim containers).

**Spec:** `docs/superpowers/specs/2026-10-02-web-light-design.md` (commit `0514c5e`). Read it before any task.

## Global Constraints

- `core/` is **import-only**. No edits to any file under `core/` or `contracts/`. If a task seems to need one, STOP and ask.
- Never import `httpx`, `requests`, `socket`, `dns`, `urllib.request`, `http.client` from `scanners/` (enforced by `tests/architecture/`). Never import another scanner.
- Scanner `name = "web"`, `version = "1.0.0"`, `supported_modes = frozenset({"light"})`, `target_types = frozenset({"domain", "url"})`, `service_hosts` left at the default (empty).
- Every `Check` declares `passive=True` explicitly; `requires_authorisation()` is computed via `core.authz.checks_require_authorisation`, never hand-set.
- At most **12** scanner-issued GETs per run; never request a path the site did not itself link, except the deterministic 404 control `/sp-404-probe-<sha256(host)[:16]>`.
- `state` is never passed to `Finding.create`; `confirmed` only via validation `passed`.
- Version-only findings: `ConfidenceEngine.combine(..., version_only=True)` (cap 0.6).
- `no_verdict_reason` values used: `timeout`, `waf_block`, `blocked_prerequisite`, `ambiguous_response`, `rate_limited` only.
- `MissingFixtureError` and `ScanKilledError` always propagate; every other request exception becomes a recorded failure.
- Gate: precision ≥ 0.95, recall ≥ 0.85, inconclusive ≤ 0.15, `recall_definition: corpus_relative`.
- Fingerprint/EOL data: every entry has `source` + `reviewed_on`; nothing sourced from Wappalyzer or its forks; EOL entries past-only (`eol_date <= reviewed_on`); freshness ≤ `core.deprecation_calendar.STALE_AFTER_DAYS` (180).
- No new runtime dependency. Lab images registered in `tools/registry.yaml` with operator sign-off.
- Line length 100, ruff rules `E,F,I,UP,B,SIM,N,RUF`, mypy `strict` on `scanners/`.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Soft-404 sites** (every unknown path returns 200 with the homepage) — must not produce a directory-listing or error-page claim; header validation still behaves. Pinned in Task 11.
2. **Apex→www redirect** — root fetched in scope on `www.`, directory candidates follow the final origin, no request leaves `*.<host>`. Pinned in Task 10.
3. **Duplicated / comma-joined headers** (`X-Frame-Options: DENY, DENY`, `nosniff, nosniff`, two CSP policies, two HSTS headers) — no false finding. Pinned in Tasks 3, 4, 10.
4. **Non-HTML root** (JSON API, empty body) — content checks clear, nothing raises. Pinned in Task 11.
5. **Malformed HTML** (unquoted attributes, unclosed tags, truncated at EOF) — the extractor never raises. Pinned in Task 2.

## Spec deviations recorded by this plan (write them into the ledger in Task 14)

- **Transport-failure corpus cases (timeout, HTTPS-unavailable) are unit tests, not frozen cases.** A failed request writes no HTTP fixture, and replay of an unrecorded URL raises `MissingFixtureError`, which this scanner deliberately propagates. (Domscout's `servfail` case relies on its scanner catching `Exception`, which also swallows `MissingFixtureError` — a latent fixture-gap hazard, recorded as an observation, not fixed here.)
- **The challenge-page case is unit-tested only** until a real interstitial can be recorded from an operator-controlled CDN (D-W2). A hand-written challenge page in the lab would encode our assumptions.
- **`web-debug-mode` covers Django's `DEBUG=True` technical 404, not the Werkzeug debugger**: Werkzeug renders its console only on an unhandled exception, which a Light 404 probe never provokes.
- **The error-page lab positive is a real Python traceback** (stdlib server), not PHP: the PHP licence is not on `cli/licences.py`'s approved list.

```python
"""Extract the facts the web checks read from one HTML document.

Stdlib `html.parser` only. Forgiving by design: real pages are malformed, and
an extractor that raised on bad markup would turn a messy page into an
"inconclusive" for every content check.
"""

from __future__ import annotations

from dataclasses import dataclass
from html.parser import HTMLParser
from urllib.parse import urljoin, urlsplit


@dataclass(frozen=True)
class Script:
    src: str
    integrity: str | None


@dataclass(frozen=True)
class PageFacts:
    scripts: tuple[Script, ...]
    stylesheets: tuple[str, ...]
    meta_csp: tuple[str, ...]
    generator: str | None
    asset_urls: tuple[str, ...]


class _Extractor(HTMLParser):
    def __init__(self, base_url: str) -> None:
        super().__init__(convert_charrefs=True)
        self.base_url = base_url
        self.scripts: list[Script] = []
        self.stylesheets: list[str] = []
        self.meta_csp: list[str] = []
        self.generator: str | None = None
        self.assets: list[str] = []

    def _abs(self, value: str) -> str:
        return urljoin(self.base_url, value.strip())

    def handle_starttag(self, tag: str, attrs: list[tuple[str, str | None]]) -> None:
        a = {k.lower(): (v or "") for k, v in attrs}
        if tag == "script" and a.get("src"):
            url = self._abs(a["src"])
            self.scripts.append(Script(src=url, integrity=a.get("integrity") or None))
            self.assets.append(url)
        elif tag == "link" and a.get("href"):
            url = self._abs(a["href"])
            if "stylesheet" in a.get("rel", "").lower().split():
                self.stylesheets.append(url)
            self.assets.append(url)
        elif tag == "img" and a.get("src"):
            self.assets.append(self._abs(a["src"]))
        elif tag == "meta":
            equiv = a.get("http-equiv", "").strip().lower()
            name = a.get("name", "").strip().lower()
            if equiv == "content-security-policy" and a.get("content"):
                self.meta_csp.append(a["content"])
            elif name == "generator" and a.get("content") and self.generator is None:
                self.generator = a["content"].strip()

    def handle_startendtag(self, tag: str, attrs: list[tuple[str, str | None]]) -> None:
        self.handle_starttag(tag, attrs)


def extract(body: str, base_url: str) -> PageFacts:
    parser = _Extractor(base_url)
    parser.feed(body or "")
    parser.close()
    return PageFacts(
        scripts=tuple(parser.scripts),
        stylesheets=tuple(parser.stylesheets),
        meta_csp=tuple(parser.meta_csp),
        generator=parser.generator,
        asset_urls=tuple(parser.assets),
    )


def _origin(url: str) -> tuple[str, str, int | None]:
    parts = urlsplit(url)
    return parts.scheme.lower(), (parts.hostname or "").lower(), parts.port


def is_same_origin(url: str, base_url: str) -> bool:
    return _origin(url) == _origin(base_url)


def _parent(path: str) -> str | None:
    if "/" not in path:
        return None
    parent = path.rsplit("/", 1)[0] + "/"
    return None if parent == "/" else parent


def same_origin_directories(facts: PageFacts, base_url: str, limit: int = 4) -> list[str]:
    dirs = {
        parent
        for url in facts.asset_urls
        if is_same_origin(url, base_url) and (parent := _parent(urlsplit(url).path))
    }
    return sorted(dirs)[:limit]


def linked_files(facts: PageFacts, base_url: str) -> dict[str, frozenset[str]]:
    grouped: dict[str, set[str]] = {}
    for url in facts.asset_urls:
        if not is_same_origin(url, base_url):
            continue
        path = urlsplit(url).path
        parent = _parent(path)
        name = path.rsplit("/", 1)[-1]
        if parent and name:
            grouped.setdefault(parent, set()).add(name)
    return {d: frozenset(n) for d, n in grouped.items()}
```

```python
"""Header parsing and verdicts. Pure: a Mapping in, a verdict out.

Repeated headers arrive comma-joined (core's capture uses dict(headers)), so
every list-valued verdict tolerates "DENY, DENY" rather than misreading it.

from __future__ import annotations

import re
from collections.abc import Mapping
from typing import Literal

HSTS_MIN_MAX_AGE = 15_768_000
"""Six months - Mozilla Observatory's threshold for a meaningful HSTS policy."""

_MAX_AGE = re.compile(r'max-age\s*=\s*"?(\d+)"?', re.IGNORECASE)
REFERRER_VALID = frozenset({
    "no-referrer", "no-referrer-when-downgrade", "same-origin", "origin", "strict-origin",
    "origin-when-cross-origin", "strict-origin-when-cross-origin", "unsafe-url",
})
REFERRER_UNSAFE = frozenset({"unsafe-url", "no-referrer-when-downgrade"})


def get(headers: Mapping[str, str], name: str) -> str | None:
    wanted = name.lower()
    for key, value in headers.items():
        if key.lower() == wanted:
            return value
    return None


def _tokens(value: str | None) -> set[str]:
    return {t.strip().lower() for t in (value or "").split(",") if t.strip()}


def hsts_verdict(value: str | None) -> tuple[Literal["missing", "weak", "ok"], int | None]:
    if value is None or not value.strip():
        return "missing", None
    first = value.split(",")[0]  # RFC 6797 8.1: only the first header is processed
    match = _MAX_AGE.search(first)
    if match is None:
        return "weak", None
    age = int(match.group(1))
    return ("ok" if age >= HSTS_MIN_MAX_AGE else "weak"), age


def xfo_protects(value: str | None) -> bool:
    tokens = _tokens(value)
    return bool(tokens) and tokens <= {"deny", "sameorigin"}


def xcto_ok(value: str | None) -> bool:
    return _tokens(value) == {"nosniff"}


def referrer_verdict(value: str | None) -> tuple[Literal["missing", "unsafe", "ok"], str | None]:
    known = [t.strip().lower() for t in (value or "").split(",")
             if t.strip().lower() in REFERRER_VALID]
    if not known:
        return "missing", None
    effective = known[-1]  # the last recognised token wins (Referrer Policy spec)
    return ("unsafe" if effective in REFERRER_UNSAFE else "ok"), effective


def cors_wildcard(value: str | None) -> bool:
    return value is not None and "*" in {t.strip() for t in value.split(",")}
```

```python
"""Content-Security-Policy parsing and script-policy grading.

Presence is not protection: a CSP with 'unsafe-inline' is close to worthless
(docs/05-phase-1-first-tools.md, Tool 4 gotchas). Multiple policies are all
enforced, so a weakness counts only if every policy permits it.
"""

from __future__ import annotations

from dataclasses import dataclass
from functools import reduce

ALL_WEAKNESSES = frozenset({"unsafe-inline", "unsafe-eval", "wildcard", "scheme-http",
                            "scheme-data"})
_NONCE_OR_HASH = ("'nonce-", "'sha256-", "'sha384-", "'sha512-")


@dataclass(frozen=True)
class Policy:
    directives: dict[str, tuple[str, ...]]


def parse(value: str | None) -> list[Policy]:
    if not value:
        return []
    policies: list[Policy] = []
    for chunk in value.split(","):
        directives: dict[str, tuple[str, ...]] = {}
        for part in chunk.split(";"):
            tokens = part.strip().split()
            if not tokens:
                continue
            name = tokens[0].lower()
            if name not in directives:  # CSP3: the first occurrence wins
                directives[name] = tuple(t.lower() for t in tokens[1:])
        if directives:
            policies.append(Policy(directives))
    return policies


def script_sources(policy: Policy) -> tuple[str, ...] | None:
    if "script-src" in policy.directives:
        return policy.directives["script-src"]
    return policy.directives.get("default-src")


def weaknesses(policy: Policy) -> frozenset[str]:
    sources = script_sources(policy)
    if sources is None:
        return ALL_WEAKNESSES
    exempt = "'strict-dynamic'" in sources or any(s.startswith(_NONCE_OR_HASH) for s in sources)
    found: set[str] = set()
    if "'unsafe-inline'" in sources and not exempt:
        found.add("unsafe-inline")
    if "'unsafe-eval'" in sources:
        found.add("unsafe-eval")
    if "*" in sources:
        found.add("wildcard")
    if "http:" in sources:
        found.add("scheme-http")
    if "data:" in sources:
        found.add("scheme-data")
    return frozenset(found)


def effective_weaknesses(policies: list[Policy]) -> frozenset[str]:
    if not policies:
        return frozenset()
    return reduce(lambda a, b: a & b, (weaknesses(p) for p in policies))


def restricts_scripts(policies: list[Policy]) -> bool:
    return any(script_sources(p) is not None for p in policies)


def has_frame_ancestors(policies: list[Policy]) -> bool:
    return any("frame-ancestors" in p.directives for p in policies)
```

```python
"""Directory-listing (autoindex) detection.

A title or marker the server itself generates, never prose: "Index of" in a
blog post is not a listing.
"""

from __future__ import annotations

import re
from dataclasses import dataclass
from urllib.parse import unquote

_KINDS: tuple[tuple[str, re.Pattern[str]], ...] = (
    ("index-of", re.compile(r"<title>\s*Index of /[^<]*</title>", re.IGNORECASE)),
    ("python-http-server", re.compile(r"<title>\s*Directory listing for /[^<]*</title>",
                                      re.IGNORECASE)),
    ("iis", re.compile(r"\[To Parent Directory\]")),
)
_HREF = re.compile(r'<a\s[^>]*href="([^"]+)"', re.IGNORECASE)


@dataclass(frozen=True)
class Listing:
    kind: str
    entries: frozenset[str]


def detect(body: str) -> Listing | None:
    if not body:
        return None
    kind = next((name for name, pattern in _KINDS if pattern.search(body)), None)
    if kind is None:
        return None
    entries: set[str] = set()
    for href in _HREF.findall(body):
        if href.startswith(("?", "#")) or href in ("/", "../", "./") or "://" in href:
            continue
        name = unquote(href.split("?")[0]).rstrip("/").rsplit("/", 1)[-1]
        if name and name != "..":
            entries.add(name)
    return Listing(kind=kind, entries=frozenset(entries))
```

```python
"""Technology detection, driven entirely by data/fingerprints.yaml.

Data, not code, because this database grows for years (05-phase-1 Tool 4).
Authored from vendor documentation and our own observation only — never
seeded from another tool's fingerprint data (SPEC A1 licence guardrail).
Cookie-name signals are unavailable: core redacts Set-Cookie whole (D-W1).
"""

from __future__ import annotations

import re
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from datetime import date
from pathlib import Path
from typing import Any

import yaml

from scanners.web.headers import get

DATA = Path(__file__).parent / "data" / "fingerprints.yaml"


@dataclass(frozen=True)
class Fingerprint:
    name: str
    category: str
    source: str
    reviewed_on: date
    headers: tuple[tuple[str, re.Pattern[str]], ...]
    html: tuple[re.Pattern[str], ...]
    asset: tuple[re.Pattern[str], ...]
    generator: tuple[re.Pattern[str], ...]


@dataclass(frozen=True)
class Detection:
    name: str
    category: str
    version: str | None
    evidence: str
    source: str


def _patterns(values: Sequence[str] | None) -> tuple[re.Pattern[str], ...]:
    return tuple(re.compile(v, re.IGNORECASE) for v in (values or []))


def load(path: Path = DATA) -> tuple[Fingerprint, ...]:
    raw: list[dict[str, Any]] = yaml.safe_load(path.read_text())
    out = []
    for entry in raw:
        match = entry.get("match") or {}
        out.append(Fingerprint(
            name=entry["name"],
            category=entry["category"],
            source=entry["source"],
            reviewed_on=entry["reviewed_on"],
            headers=tuple((k.lower(), re.compile(v, re.IGNORECASE))
                          for k, v in (match.get("headers") or {}).items()),
            html=_patterns(match.get("html")),
            asset=_patterns(match.get("asset")),
            generator=_patterns(match.get("generator")),
        ))
    return tuple(out)


def detect(
    fingerprints: Sequence[Fingerprint],
    *,
    headers: Mapping[str, str],
    body: str,
    asset_urls: Sequence[str],
    generator: str | None,
) -> list[Detection]:
    detections = []
    for fp in fingerprints:
        version: str | None = None
        evidence: str | None = None

        def hit(match: re.Match[str], where: str) -> None:
            nonlocal version, evidence
            evidence = evidence or where
            version = version or match.groupdict().get("version")

        for name, pattern in fp.headers:
            value = get(headers, name)
            if value and (m := pattern.search(value)):
                hit(m, f"{name}: {value}")
        for pattern in fp.generator:
            if generator and (m := pattern.search(generator)):
                hit(m, f"meta generator: {generator}")
        for pattern in fp.asset:
            for url in asset_urls:
                if m := pattern.search(url):
                    hit(m, f"asset: {url}")
        for pattern in fp.html:
            if body and (m := pattern.search(body)):
                hit(m, f"markup matching {pattern.pattern}")
        if evidence:
            detections.append(Detection(fp.name, fp.category, version, evidence, fp.source))
    return detections
```

```python
"""End-of-life branch matching, driven by data/eol.yaml.

Only branches already past end-of-life when the entry was written are listed,
so no entry ever changes status at runtime and frozen fixtures cannot rot.
Freshness is a CI property (tests/scanners/web/test_data.py), not a runtime one.
"""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from datetime import date
from pathlib import Path
from typing import Any

import yaml

DATA = Path(__file__).parent / "data" / "eol.yaml"


@dataclass(frozen=True)
class EolEntry:
    product: str
    branch: str
    eol_date: date
    source: str
    reviewed_on: date


def load(path: Path = DATA) -> tuple[EolEntry, ...]:
    raw: list[dict[str, Any]] = yaml.safe_load(path.read_text())
    return tuple(EolEntry(e["product"], str(e["branch"]), e["eol_date"], e["source"],
                          e["reviewed_on"]) for e in raw)


def branch_matches(version: str, branch: str) -> bool:
    v, b = version.split("."), branch.split(".")
    return v[: len(b)] == b


def match(entries: Sequence[EolEntry], product: str, version: str) -> EolEntry | None:
    candidates = [e for e in entries if e.product == product and branch_matches(version, e.branch)]
    return max(candidates, key=lambda e: len(e.branch.split(".")), default=None)
```

```python
class FakeSite:
    def __init__(self, host: str = "x.test", default=NOT_FOUND) -> None:
        self.host = host
        self.default = default
        self.responses: dict[str, tuple[int, dict[str, str], str]] = {}
        self.fail: dict[str, Exception] = {}
        self.calls: list[str] = []

    def serve(self, url, status=200, headers=None, body=""):
        self.responses[url] = (status, dict(headers or {}), body)
        return self

    def raise_on(self, url, exc):

        status, headers, body = self.responses.get(url, self.default)
        return RawHttpResponse(status_code=status, headers=dict(headers), text=body, url=url,
                               elapsed_ms=1)

    def ctx(self) -> ScanContext:
        scope = Scope(frozenset({self.host}))
        return ScanContext(http=HttpClient(scope=scope, backend=self), scope=scope)
```

```python
"""The bounded request plan (design spec section 2).

At most MAX_REQUESTS ordinary GETs, made once, in a fixed order. Nothing is
requested that the site did not point at itself, except the deterministic 404
control. Deterministic, not random: a random path would never match a frozen
fixture on replay.

A failed request is recorded, never raised - except MissingFixtureError (a
corpus gap is a bug, not a target condition) and ScanKilledError.
"""

from __future__ import annotations

import hashlib
from dataclasses import dataclass
from urllib.parse import urlsplit

from core.context import ScanContext
from core.http import CapturedResponse, HttpClient, MissingFixtureError, OutOfScopeError
from core.killswitch import ScanKilledError
from core.models import Asset
from scanners.web import challenge, html
from scanners.web.headers import get

MAX_REQUESTS = 12
MAX_DIRECTORIES = 4
MAX_SITEMAPS = 2
PROBE_PREFIX = "sp-404-probe-"


def probe_path(host: str) -> str:
    return f"/{PROBE_PREFIX}{hashlib.sha256(host.encode()).hexdigest()[:16]}"


@dataclass(frozen=True)
class Fetched:
    label: str
    url: str
    path: str
    response: CapturedResponse | None
    failure: str | None

    @property
    def usable(self) -> bool:
        return self.response is not None and self.failure is None

    @property
    def final_scheme(self) -> str | None:
        return urlsplit(self.response.url).scheme.lower() if self.response else None


@dataclass(frozen=True)
class Observations:
    host: str
    root_path: str
    probe_path: str
    https_root: Fetched
    http_root: Fetched
    https_probe: Fetched
    http_probe: Fetched
    robots: Fetched
    sitemaps: tuple[Fetched, ...]
    security_txt: Fetched
    directories: tuple[Fetched, ...]
    page: html.PageFacts | None
    page_url: str | None
    requests_made: int

    @property
    def root(self) -> Fetched:
        return self.https_root if self.https_root.response is not None else self.http_root

    @property
    def probe(self) -> Fetched:
        return self.https_probe if self.https_root.response is not None else self.http_probe

    def same_origin_fetches(self) -> list[Fetched]:
        candidates = [self.root, self.probe, self.robots, *self.sitemaps, self.security_txt,
                      *self.directories]
        return [f for f in candidates if f.usable]


def _origins(target: Asset) -> tuple[str, str | None, str | None, str]:
    """(host, https origin, http origin, root path). The other scheme is derived
    only on default ports - on an explicit port we cannot know it."""
    value = target.value.strip()
    if target.type == "url" or "://" in value:
        parts = urlsplit(value if "://" in value else f"https://{value}")
        host = (parts.hostname or "").lower().rstrip(".")
        path = parts.path or "/"
        if parts.port is None:
            return host, f"https://{host}", f"http://{host}", path
        netloc = f"{host}:{parts.port}"
        if parts.scheme.lower() == "https":
            return host, f"https://{netloc}", None, path
        return host, None, f"http://{netloc}", path
    host = value.lower().rstrip(".")
    return host, f"https://{host}", f"http://{host}", "/"


class _Fetcher:
    def __init__(self, ctx: ScanContext, http: HttpClient) -> None:
        self.ctx = ctx
        self.http = http
        self.count = 0

    def get(self, label: str, url: str) -> Fetched:
        path = urlsplit(url).path or "/"
        if self.count >= MAX_REQUESTS:
            raise RuntimeError("web request plan exceeded MAX_REQUESTS - a scanner bug")
        self.ctx.check_alive()
        self.count += 1
        try:
            response = self.http.get(url)
        except (MissingFixtureError, ScanKilledError):
            raise
        except OutOfScopeError:
            return Fetched(label, url, path, None, "blocked_prerequisite")
        except Exception as exc:  # a transport failure: we could not find out
            reason = "timeout" if "timeout" in type(exc).__name__.lower() else "blocked_prerequisite"
            return Fetched(label, url, path, None, reason)
        if response.status_code == 429:
            return Fetched(label, url, path, response, "rate_limited")
        if challenge.detect(response.status_code, response.headers, response.text):
            return Fetched(label, url, path, response, "waf_block")
        return Fetched(label, url, path, response, None)

    def maybe(self, label: str, origin: str | None, path: str, scheme: str, host: str) -> Fetched:
        if origin is None:
            return Fetched(label, f"{scheme}://{host}{path}", path, None, "blocked_prerequisite")
        return self.get(label, origin + path)


def _is_html(response: CapturedResponse) -> bool:
    content_type = (get(response.headers, "content-type") or "").lower()
    return "html" in content_type or response.text.lstrip()[:1] == "<"


def _sitemaps(robots: Fetched, host: str) -> list[str]:
    if not robots.usable or robots.response is None or robots.response.status_code != 200:
        return []
    urls = []
    for line in robots.response.text.splitlines():
        key, _, value = line.partition(":")
        if key.strip().lower() == "sitemap":
            url = value.strip()
            if (urlsplit(url).hostname or "").lower() == host and url not in urls:
                urls.append(url)
    return urls[:MAX_SITEMAPS]


def gather(ctx: ScanContext, http: HttpClient, target: Asset) -> Observations:
    host, https_origin, http_origin, root_path = _origins(target)
    f = _Fetcher(ctx, http)
    probe = probe_path(host)

    https_root = f.maybe("https root", https_origin, root_path, "https", host)
    http_root = f.maybe("http root", http_origin, root_path, "http", host)
    https_probe = f.maybe("https 404 control", https_origin, probe, "https", host)
    http_probe = f.maybe("http 404 control", http_origin, probe, "http", host)

    base = (https_origin if https_root.response is not None
            else http_origin if http_root.response is not None
            else https_origin or http_origin)
    assert base is not None
    robots = f.get("robots.txt", base + "/robots.txt")
    sitemaps = tuple(f.get("sitemap", url) for url in _sitemaps(robots, host))
    security_txt = f.get("security.txt", base + "/.well-known/security.txt")

    root = https_root if https_root.response is not None else http_root
    page: html.PageFacts | None = None
    page_url: str | None = None
    directories: tuple[Fetched, ...] = ()
    if root.usable and root.response is not None and _is_html(root.response):
        page_url = root.response.url
        page = html.extract(root.response.text, page_url)
        parts = urlsplit(page_url)
        origin = f"{parts.scheme}://{parts.netloc}"
        directories = tuple(
            f.get("directory", origin + d)
            for d in html.same_origin_directories(page, page_url, limit=MAX_DIRECTORIES)
        )

    return Observations(
        host=host, root_path=root_path, probe_path=probe,
        https_root=https_root, http_root=http_root, https_probe=https_probe,
        http_probe=http_probe, robots=robots, sitemaps=sitemaps, security_txt=security_txt,
        directories=directories, page=page, page_url=page_url, requests_made=f.count,
    )
```

```python
        root = self.obs.root

        if root.usable and root.response is not None:
            page = self.obs.page
            self.detections = fingerprint.detect(
                self.fingerprints, headers=root.response.headers, body=root.response.text,
                asset_urls=page.asset_urls if page else (),
                generator=page.generator if page else None,
            )
        self.edge = next((d.name for d in self.detections if d.category == "cdn"), None)

        self.ctx.progress("judging transport security", 0.4)
        self._check_https_redirect()
        self._check_hsts()
        self.ctx.progress("judging security headers", 0.55)
        self._check_header_policies()
        # Task 11 inserts the content, error-page, listing and inventory checks here.
        self.ctx.progress("done", 1.0)
        cost = self.ctx.cost.snapshot()
        return ScanResult(
            scanner=self.scanner.name, scanner_version=self.scanner.version,
            target=self.target, mode=self.mode, findings=self.findings, errors=[],
            telemetry=Telemetry(checks_run=self.checks, requests=cost.requests,
                                wall_ms=cost.wall_ms),
            finished_at=datetime.now(UTC),
        )

    # --- transport -------------------------------------------------------

    def _check_https_redirect(self) -> None:
        check, loc = CHECKS["web-https-redirect-missing"], self.obs.root_path
        https, plain = self.obs.https_root, self.obs.http_root
        if https.response is None:
            reason, text = _why_unusable(https)
            self._inconclusive(check, loc, https, f"HTTPS could not be read: {text}. Whether plain "
                               "HTTP should redirect to it cannot be judged.", reason=reason)
            return
        if not plain.usable or plain.response is None:
            reason, text = _why_unusable(plain)
            self._inconclusive(check, loc, plain, f"Plain HTTP could not be read: {text}.",
                               reason=reason)
            return
        status = plain.response.status_code
        if plain.final_scheme == "https" or not 200 <= status < 300:
            self._clear(check, loc)
            return
        self._emit(check, loc, test=plain, control=https,
                   description=(f"{plain.url} answered HTTP {status} over plain HTTP (final URL "
                                f"{plain.response.url}) instead of redirecting, while HTTPS is "
                                f"served at {https.url}"),
                   validation=self._validate_redirect())

    def _validate_redirect(self) -> dict[str, Any]:
        probe = self.obs.http_probe
        if probe.response is None or probe.failure is not None:
            return {"attempted": False, "outcome": "unavailable", "method": VALIDATION_METHOD}
        redirected = (probe.final_scheme == "https"
                      or 300 <= probe.response.status_code < 400)
        return {"attempted": True, "outcome": "failed" if redirected else "passed",
                "method": VALIDATION_METHOD}

    def _check_hsts(self) -> None:
        missing, weak = CHECKS["web-hsts-missing"], CHECKS["web-hsts-weak"]
        root, loc = self.obs.https_root, self.obs.root_path
        if not self._usable(root, [missing, weak]):
            return
        assert root.response is not None
        value = headers.get(root.response.headers, "strict-transport-security")
        verdict, age = headers.hsts_verdict(value)
        if verdict == "ok":
            self._clear(missing, loc)
            self._clear(weak, loc)
            return
        fired, other = (missing, weak) if verdict == "missing" else (weak, missing)

        def judge(h: dict[str, str], body: str) -> tuple[bool, str]:
            v, _ = headers.hsts_verdict(headers.get(h, "strict-transport-security"))
            return (v == "missing") if fired is missing else (v != "ok"), ""

        observed = ("no Strict-Transport-Security header" if verdict == "missing"
                    else f"Strict-Transport-Security {value!r} (max-age {age})")
        self._emit(fired, loc, test=root, control=self.obs.https_probe,
                   description=f"{root.response.url} is served with {observed}",
                   validation=self._validate_on_probe(judge, self.obs.https_probe))
        self._clear(other, loc)

    # --- header policies ---------------------------------------------------

    def _check_header_policies(self) -> None:
        root, probe, loc = self.obs.root, self.obs.probe, self.obs.root_path
        checks = [CHECKS[c] for c, _, _ in HEADER_POLICIES]
        if not self._usable(root, checks):
            return
        assert root.response is not None
        for check_id, judge, validate in HEADER_POLICIES:
            check = CHECKS[check_id]
            deficient, observed = judge(root.response.headers, root.response.text)
            if not deficient:
                self._clear(check, loc)
                continue
            self._emit(check, loc, test=root, control=probe,
                       description=f"{root.response.url}: {observed}",
                       validation=self._validate_on_probe(judge, probe) if validate else None)

    # --- shared helpers (Task 11 reuses these) ------------------------------

    def _usable(self, fetched: Fetched, checks: list[Check], location: str | None = None) -> bool:
        if fetched.usable and fetched.response is not None and fetched.response.status_code < 500:
            return True
        reason, text = _why_unusable(fetched)
        for check in checks:
            self._inconclusive(check, location or self.obs.root_path, fetched, text + ".",
                               reason=reason)
        return False

    def _validate_on_probe(self, judge: Judge, probe: Fetched) -> dict[str, Any]:
        if not probe.usable or probe.response is None or probe.response.status_code >= 500:
            return {"attempted": False, "outcome": "unavailable", "method": VALIDATION_METHOD}
        deficient, _ = judge(probe.response.headers, probe.response.text)
        return {"attempted": True, "outcome": "passed" if deficient else "failed",
                "method": VALIDATION_METHOD}

    def _signal(self, check: Check, independence_class: str | None = None,
                likelihood_ratio: float | None = None, justification: str | None = None) -> Signal:
        return Signal(
            method=check.check_id.replace("-", "_"),
            prior=0.5,
            likelihood_ratio=likelihood_ratio or check.likelihood_ratio,
            independence_class=independence_class or check.independence_class,
            prior_justification=justification or check.justification,
        )

    def _edge_note(self, check: Check) -> str:
        if self.edge and check.check_id in HEADER_FAMILY:
            return (f" Served through {self.edge}: the edge may add or strip headers, so this "
                    "describes what visitors receive, not necessarily what the origin sends.")
        return ""

    def _emit(self, check: Check, location: str, *, test: Fetched, control: Fetched,
              description: str, validation: dict[str, Any] | None = None,
              signals: list[Signal] | None = None, version_only: bool = False,
              instance_key: str | None = None, references: list[str] | None = None) -> None:
        result = self.engine.combine(signals or [self._signal(check)], version_only=version_only)
        evidence = [capture_http_pair(
            label=f"{check.check_id} at {location}",
            control_request=_request(control), control_response=_raw(control),
            test_request=_request(test), test_response=_raw(test),
            delta={"test": test.label, "control": control.label},
        )]
        now = datetime.now(UTC)
        self.findings.append(Finding.create(
            org_id=self.ctx.org_id, scanner=self.scanner.name,
            scanner_version=self.scanner.version, check_id=check.check_id, title=check.title,
            target=self.target, location=location, instance_key=instance_key,
            severity=check.severity, confidence=result.confidence,
            confidence_provisional=result.provisional,
            detection_methods=result.detection_methods,
            validation=validation or {"attempted": False, "outcome": "not_applicable"},
            evidence=evidence, description=description.rstrip(".") + "." + self._edge_note(check),
            impact=check.impact, remediation=check.remediation, references=references or [],
            taxonomy={}, first_seen=now, first_seen_scan_id=self.ctx.scan_id, last_seen=now,
            last_seen_scan_id=self.ctx.scan_id, cost=self.ctx.cost.snapshot(),
        ))
        self.checks.append(CheckRun(check_id=check.check_id, location=location, outcome="reported"))

    def _inconclusive(self, check: Check, location: str, fetched: Fetched, description: str, *,
                      reason: str) -> None:
        result = self.engine.combine([self._signal(
            check, likelihood_ratio=1.0,
            justification="the request produced no usable answer, so nothing moves the prior")])
        raw = _raw(fetched)
        evidence = [capture_http_pair(
            label=f"{check.check_id} at {location}",
            control_request=_request(fetched), control_response=raw,
            test_request=_request(fetched), test_response=raw,
            delta={"note": "no usable response; test and control are the same failed request"},
        )]
        now = datetime.now(UTC)
        self.findings.append(Finding.create(
            org_id=self.ctx.org_id, scanner=self.scanner.name,
            scanner_version=self.scanner.version, check_id=check.check_id, title=check.title,
            target=self.target, location=location, severity=check.severity,
            confidence=result.confidence, confidence_provisional=result.provisional,
            no_verdict_reason=reason if reason in NO_VERDICT else "blocked_prerequisite",
            detection_methods=result.detection_methods,
            validation={"attempted": False, "outcome": "unavailable"},
            evidence=evidence, description=description,
            impact="Unknown until the request succeeds.",
            remediation=("Re-run the scan. A persistent failure means the site is unreachable "
                         "from the scanner, or an edge is blocking it."),
            references=[], taxonomy={}, first_seen=now, first_seen_scan_id=self.ctx.scan_id,
            last_seen=now, last_seen_scan_id=self.ctx.scan_id, cost=self.ctx.cost.snapshot(),
        ))
        self.checks.append(CheckRun(check_id=check.check_id, location=location,
                                    outcome="inconclusive"))

    def _clear(self, check: Check, location: str) -> None:
        self.checks.append(CheckRun(check_id=check.check_id, location=location, outcome="clear"))
```

```python
    def _check_listings(self) -> None:
        check = CHECKS["web-directory-listing"]
        root, page, page_url = self.obs.root, self.obs.page, self.obs.page_url
        linked = html.linked_files(page, page_url) if page and page_url else {}
        for f in (root, *self.obs.directories):
            loc = f.path
            if f.response is None or f.failure is not None:
                reason, text = _why_unusable(f)
                self._inconclusive(check, loc, f, text + ".", reason=reason)
                continue
            found = listing.detect(f.response.text) if f.response.status_code == 200 else None
            if found is None:
                self._clear(check, loc)
                continue
            signals = [self._signal(check)]
            corroborated = (sorted(found.entries & linked.get(loc, frozenset()))
                            if f is not root else [])
            if corroborated:
                signals.append(self._signal(
                    check, HTML_DOCUMENT, likelihood_ratio=5.0,
                    justification=("a file the homepage itself links appears in the listing - a "
                                   "second document agreeing with the first")))
            note = (f" It includes {', '.join(corroborated)}, which the homepage links to."
                    if corroborated else "")
            self._emit(check, loc, test=f, control=self.obs.probe, signals=signals,
                       description=(f"{f.url} returns a generated directory listing "
                                    f"({found.kind}) of {len(found.entries)} entr"
                                    f"{'y' if len(found.entries) == 1 else 'ies'}.{note}"))

    # --- inventory ---------------------------------------------------------------

    def _check_robots(self) -> None:
        check, f = CHECKS["web-robots-paths"], self.obs.robots
        if f.response is None or f.failure is not None:
            reason, text = _why_unusable(f)
            self._inconclusive(check, f.path, f, text + ".", reason=reason)
            return
        if f.response.status_code != 200:
            self._clear(check, f.path)
            return
        disallowed, sitemaps = _robots_entries(f.response.text)
        if not disallowed and not sitemaps:
            self._clear(check, f.path)
            return
        self._emit(check, f.path, test=f, control=self.obs.probe,
                   description=(f"robots.txt disallows {disallowed or 'nothing'} and names "
                                f"sitemaps {sitemaps or 'none'}. These paths were not fetched"))

    def _check_security_txt(self) -> None:
        check, f = CHECKS["web-security-txt-missing"], self.obs.security_txt
        if f.response is None or f.failure is not None:
            reason, text = _why_unusable(f)
            self._inconclusive(check, f.path, f, text + ".", reason=reason)
            return
        if f.response.status_code == 200 and re.search(r"(?im)^contact:", f.response.text):
            self._clear(check, f.path)
            return
        self._emit(check, f.path, test=f, control=self.obs.root,
                   description=(f"{f.url} answered HTTP {f.response.status_code} without an "
                                "RFC 9116 Contact field"))
```

```python
def _robots_entries(text: str) -> tuple[list[str], list[str]]:
    """Disallow paths and Sitemap URLs, in order, deduplicated. Split on the
    first colon only, so a Sitemap URL keeps its own "https://"."""
    disallowed: list[str] = []
    sitemaps: list[str] = []
    for line in text.splitlines():
        key, _, value = line.partition(":")
        key, value = key.strip().lower(), value.strip()
        if key == "disallow":
            value = value.split("#", 1)[0].strip()
            if value and value not in disallowed:
                disallowed.append(value)
        elif key == "sitemap" and value and value not in sitemaps:
            sitemaps.append(value)
    return disallowed, sitemaps
```

```python
"""A stdlib server that leaks a real Python traceback for unknown paths. Lab only."""
import html
import traceback
from http.server import BaseHTTPRequestHandler, HTTPServer

ROUTES = {"/": "<!doctype html><html><head><title>pytrace lab</title></head><body>ok</body></html>"}


class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        try:
            body, status = ROUTES[self.path.split("?")[0]], 200
        except KeyError:
            body, status = "<pre>" + html.escape(traceback.format_exc()) + "</pre>", 500
        data = body.encode()
        self.send_response(status)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)


HTTPServer(("0.0.0.0", 8000), Handler).serve_forever()
```

```python
"""Record the frozen HTTP fixtures for the web (Tool 4a) corpus from the local lab.

    make web-lab-up                                  # certs + containers
    uv run python -m corpus.generators.web record    # record every case

Every case is recorded by running the scanner itself through a recording
backend, so what is frozen is exactly what the scanner asks for. Requests for
<case>.web.test are routed to the lab on 127.0.0.1 with the original Host and
SNI, and the recorded URL is the original one, so replay needs no DNS.
"""

from __future__ import annotations

import datetime as dt
import shutil
import ssl
import sys
from pathlib import Path
from typing import Any

import httpx
from cryptography import x509
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.x509.oid import ExtendedKeyUsageOID, NameOID

from core.authz import Scope
from core.context import ScanContext
from core.http import DEFAULT_USER_AGENT, HttpClient, RawHttpResponse, RecordingHttpBackend
from core.models import Asset
from scanners.web import WebScanner

ROOT = Path(__file__).resolve().parents[2]
CERTS = ROOT / "corpus" / "lab" / "web" / "certs"
FIXTURES = ROOT / "corpus" / "fixtures" / "web"
HTTP_PORT, HTTPS_PORT = 18080, 18443
CASES = ("known-good", "bare", "hsts-weak", "csp-weak", "csp-meta", "listing", "mixed-sri",
         "secret", "eol", "django-debug", "pytrace")


def mint() -> None:
    """A throwaway lab CA and a *.web.test leaf. Python 3.13's default
    VERIFY_X509_STRICT needs the key-identifier extensions, so both are set."""
    CERTS.mkdir(parents=True, exist_ok=True)
    now = dt.datetime.now(dt.UTC)
    ca_key, leaf_key = ec.generate_private_key(ec.SECP256R1()), ec.generate_private_key(ec.SECP256R1())
    ca_name = x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, "Security-Platform web lab CA")])
    ca = (x509.CertificateBuilder().subject_name(ca_name).issuer_name(ca_name)
          .public_key(ca_key.public_key()).serial_number(x509.random_serial_number())
          .not_valid_before(now - dt.timedelta(days=1)).not_valid_after(now + dt.timedelta(days=3650))
          .add_extension(x509.BasicConstraints(ca=True, path_length=0), critical=True)
          .add_extension(x509.KeyUsage(digital_signature=True, key_cert_sign=True, crl_sign=True,
                                       content_commitment=False, key_encipherment=False,
                                       data_encipherment=False, key_agreement=False,
                                       encipher_only=False, decipher_only=False), critical=True)
          .add_extension(x509.SubjectKeyIdentifier.from_public_key(ca_key.public_key()), critical=False)
          .sign(ca_key, hashes.SHA256()))
    leaf = (x509.CertificateBuilder()
            .subject_name(x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, "*.web.test")]))
            .issuer_name(ca_name).public_key(leaf_key.public_key())
            .serial_number(x509.random_serial_number())
            .not_valid_before(now - dt.timedelta(days=1)).not_valid_after(now + dt.timedelta(days=825))
            .add_extension(x509.SubjectAlternativeName([x509.DNSName("*.web.test")]), critical=False)
            .add_extension(x509.BasicConstraints(ca=False, path_length=None), critical=True)
            .add_extension(x509.ExtendedKeyUsage([ExtendedKeyUsageOID.SERVER_AUTH]), critical=False)
            .add_extension(x509.SubjectKeyIdentifier.from_public_key(leaf_key.public_key()), critical=False)
            .add_extension(x509.AuthorityKeyIdentifier.from_issuer_public_key(ca_key.public_key()), critical=False)
            .sign(ca_key, hashes.SHA256()))
    pem = serialization.Encoding.PEM
    (CERTS / "ca.crt").write_bytes(ca.public_bytes(pem))
    (CERTS / "web-lab.crt").write_bytes(leaf.public_bytes(pem))
    (CERTS / "web-lab.key").write_bytes(leaf_key.private_bytes(
        pem, serialization.PrivateFormat.TraditionalOpenSSL, serialization.NoEncryption()))


class LabBackend:
    """Routes <case>.web.test to the lab, keeping the original URL in the response."""

    def __init__(self, ca: Path) -> None:
        context = ssl.create_default_context(cafile=str(ca))
        self._client = httpx.Client(verify=context, follow_redirects=False, timeout=10.0)

    def send(self, method: str, url: str, *, body_cap: int, **kwargs: Any) -> RawHttpResponse:
        del body_cap
        original = httpx.URL(url)
        port = HTTPS_PORT if original.scheme == "https" else HTTP_PORT
        routed = original.copy_with(host="127.0.0.1", port=port)
        response = self._client.request(
            method, routed, headers={"Host": original.host, "User-Agent": DEFAULT_USER_AGENT},
            extensions={"sni_hostname": original.host})
        return RawHttpResponse(status_code=response.status_code, headers=dict(response.headers),
                               text=response.text, url=url,
                               elapsed_ms=int(response.elapsed.total_seconds() * 1000))


def record() -> None:
    ca = CERTS / "ca.crt"
    if not ca.exists():
        sys.exit("no lab CA - run `make web-lab-up` first")
    backend = LabBackend(ca)
    for case in CASES:
        host = f"{case}.web.test"
        directory = FIXTURES / case
        shutil.rmtree(directory, ignore_errors=True)
        directory.mkdir(parents=True)
        scope = Scope(frozenset({host}))
        ctx = ScanContext(http=HttpClient(scope=scope, backend=RecordingHttpBackend(directory, backend)),
                          scope=scope, progress=lambda message, fraction: None)
        result = WebScanner().run(Asset(type="domain", value=host), "light", ctx)
        claims = sorted(f"{f.check_id}@{f.location}" for f in result.findings
                        if f.state in ("confirmed", "highly_likely"))
        others = sorted(f"{f.check_id}:{f.state}" for f in result.findings
                        if f.state not in ("confirmed", "highly_likely", "informational"))
        print(f"{case}: claims={claims} other={others}")


if __name__ == "__main__":
    {"certs": mint, "record": record}[sys.argv[1] if len(sys.argv) > 1 else "record"]()
```
