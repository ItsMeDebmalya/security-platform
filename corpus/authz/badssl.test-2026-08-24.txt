# Proof of control for badssl.test (and *.badssl.test)
# Method: self_owned (docs/09-ownership-verification.md)
# Recorded: 2026-08-24 by operator:satwik
#
# badssl.com, run locally. This is the TLS ground-truth corpus that
# docs/05-phase-1-first-tools.md names for Tool 2: dozens of subdomains each
# broken in exactly one known way - expired, self-signed, wrong-host, rc4,
# dh512, sha1-intermediate, no-subject, incomplete-chain - so each is its own
# ground-truth case with a knowable right answer.
#
# ---------------------------------------------------------------------------
# WHY THIS IS SELF-OWNED
# ---------------------------------------------------------------------------
#
# `.test` is reserved by RFC 2606 and resolves for nobody on the public
# internet. These names exist only in the operator's own hosts file, pointing
# at a container the operator started. There is no badssl.test anywhere to
# confuse this with, and a scan of it reaches nothing but loopback.
#
# This is deliberately NOT the public badssl.com. That host is run by other
# people, and pointing an automated corpus run at it is not something we have
# permission to do. Light mode is passive and may touch it; Standard and Deep
# may not, and no row here authorises them to.
#
# ---------------------------------------------------------------------------
# UPSTREAM AND SETUP
# ---------------------------------------------------------------------------
#
# Project : https://github.com/chromium/badssl.com
# Licence : Apache-2.0
#
#   $ git clone https://github.com/chromium/badssl.com
#   $ cd badssl.com
#   $ make list-hosts        # append the output to /etc/hosts
#   $ make serve
#
# The trust anchor for the generated certificates is at
# certs/sets/test/gen/crt/ca-root.crt. Add it to the trust store of whatever
# is doing the scanning, or every case will read as "untrusted issuer" and the
# more specific findings will be masked.
#
# ON WSL: /etc/hosts inside the distro is regenerated by WSL on each boot
# unless you disable it. Put this in /etc/wsl.conf first, then `wsl --shutdown`:
#
#   [network]
#   generateHosts = false
#
# Without that, the badssl.test entries disappear and every TLS case turns
# into a DNS failure - which the scanner will correctly report as inconclusive
# rather than as a TLS finding, but you will have lost the corpus.
#
# ---------------------------------------------------------------------------
# OPERATOR CHECK, BEFORE SCANNING
# ---------------------------------------------------------------------------
#
#   $ getent hosts expired.badssl.test          # resolves to 127.0.0.1
#   $ openssl s_client -connect expired.badssl.test:443 \
#       -servername expired.badssl.test </dev/null 2>&1 | head -20
